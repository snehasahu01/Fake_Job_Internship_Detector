# Fake Job and Internship Detector

## Project Overview
This project uses machine learning to classify job postings as genuine or potentially fraudulent.

## Technologies Used
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression

## Current Features
- Dataset inspection and preprocessing
- Text feature extraction using TF-IDF
- Machine learning model training
- Model evaluation using accuracy, precision, recall, F1-score, and confusion matrix

## Project Status
Machine learning training pipeline completed. API and frontend development are planned.
